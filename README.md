# ND · Portafolio de ingeniería de sistemas

Portafolio adaptable en HTML, CSS y JavaScript, sin compilación ni dependencias de ejecución. Incluye entrada animada, partículas sensibles al cursor, ilustración orbital, filtros de proyectos, detalles en diálogos, terminal interactiva y copia de correo.

## Ejecutar

Desde `/workspace/PORFOLIO`:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

También puedes abrir `index.html` directamente. Para el portapapeles, utiliza localhost o HTTPS.

## Personalizar

- `index.html`: nombre, biografía, habilidades y contacto. Busca `hola@example.com` y reemplázalo también en `app.js`.
- `app.js`: descripciones de los cuatro proyectos conceptuales y respuestas de la terminal.
- `styles.css`: colores, tipografías, distribución y animaciones.

La biografía, las habilidades y los proyectos son ejemplos, no experiencia acreditada. Sustituye el contenido antes de publicar. El correo de ejemplo no recibe mensajes para ti.

Dirección visual original con referencias generales del estilo editorial de galerías como Awwwards y sitios de inspiración como Dribbble; no se descargaron ni copiaron diseños de esas plataformas. Fotografías alojadas en Unsplash y fuentes de Google Fonts requieren conexión. El sitio usa fuentes de sistema si las fuentes externas no cargan; los fondos mantienen legible el contenido si faltan las fotografías. Para uso sin conexión, descarga recursos con sus licencias y actualiza las rutas.

Respeta la preferencia de movimiento reducido del sistema. La navegación, los filtros y los diálogos funcionan con teclado.
